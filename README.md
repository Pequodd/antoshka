# Climate Solution Pro — прототипы сайта

Концепции лендинга для подрядчика по кондиционированию, вентиляции и электромонтажу (Челябинск, Екатеринбург).

| Папка | Что внутри |
|---|---|
| `v7/` | V6 + 50% стилистики numa.uprock.pro: капсулы, «воздушный» синий, цифры со свечением, таймлайн, плавный скролл |
| `v6/` | V5 + цены и прайс доп. работ, полоса доверия, объекты, отзывы, FAQ, быстрый расчёт в форме |
| `v5/` | Термостат на первом экране, услуги вкладками, процесс лентой, блок оборудования из V4 |
| `v4/` | Светлая версия: графитовое облако точек (WebGL), оранжевая линия LiDAR-сканирования |
| `v3/` | Тёмная версия: светящийся кондиционер из точек, поток холода и тепла |
| `scroll-3d/` | Две полноэкранные секции со скролл-анимацией по кадрам |
| `assets/` | Видео: 3D-рендеры кондиционера, ролик с командой, постер |

Стартовая страница — `index.html`. Цифры и имена в квадратных скобках — заглушки.

Публикуется через GitHub Pages из ветки `main`, корень репозитория.
